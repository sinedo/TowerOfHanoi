Tower of Hanoi: All Possible States and Valid Moves (3 Disks)

This section lists all 27 unique valid states for the Tower of Hanoi puzzle with 3 disks (labeled 1, 2, 3, where 1 is the smallest) and 3 pegs (A, B, C). For each state, all possible valid moves are listed.

A state is described by the disks on each peg (from bottom-most to top-most). "empty" indicates no disks on that peg.

Moves are in the format MD<disk_number><source_peg><destination_peg>.

Only choose moves that are associated with the "Current Tower of Hanoi state"!

Always make sure, think about which disk is currently on which peg!
